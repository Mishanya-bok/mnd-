Шрифты нового сайта. Положите сюда файлы и переименуйте их так:

  widock.woff2   (или widock.otf / widock.ttf)              — Widock Trial, крупный основной
  involve-regular.woff2  (или .otf / .ttf)                   — Involve Regular, текст
  involve-medium.woff2   (или .otf / .ttf)                   — Involve Medium/SemiBold, жирный текст

Достаточно одного формата для каждого файла. Пока файлов нет, сайт показывает запасные шрифты.
Важно: Widock Trial — пробная версия; для коммерческого сайта нужна купленная лицензия.
